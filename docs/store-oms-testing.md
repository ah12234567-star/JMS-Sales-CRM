# Store OMS Test Matrix

- Create valid order.
- Reject empty order.
- Reject missing/invalid item.
- Approve order and reserve inventory.
- Prevent invalid status jumps.
- Move through picking, ready, loaded, out for delivery, delivered.
- Consume inventory at loaded.
- Cancel before/at ready with reason and release reservation.
- Prevent non-admin cancellation after ready.
- Allow admin cancellation after ready according to policy.
- Verify audit history entries contain from/to/user/timestamp.
- Verify sales search/filter/order details.
- Verify warehouse operational filtering.
- Verify A4 pick/dispatch print layout.
- Verify realtime new order/status refresh.
